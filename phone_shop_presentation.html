Technical Highlights

What Makes It Work

Core engineering decisions behind the application's reliability and usability.

F-01
🔒
Input Validation

Every field is checked before a database write. Price must be a positive float, stock a positive integer, names non-empty. Errors shown via messagebox dialogs.

F-02
🔗
Cascade Deletion

Deleting a phone or customer triggers deletion of all linked orders first, keeping the database consistent with no orphan records.

F-03
📦
Real-Time Stock

Placing an order reduces stock by quantity. Cancelling restores it. Stock ≤ 2 triggers a ⚠️ LOW warning both in the phone list and the dashboard.

F-04
🔍
Multi-Field Search

SQL LIKE queries with wildcards across all relevant columns. Orders can be searched by order ID, customer name, phone brand, model, or date simultaneously.

F-05
🔄
ID Resequencing

After deleting an order, the resequence_orders() function reassigns all IDs from 1 upwards and resets the AUTOINCREMENT counter — no gaps remain.

F-06
💾
Persistent Storage

The database file is saved next to the script using os.path, so data survives application restarts without any configuration needed.

Place Order — Core Logic

Demonstrates validation, foreign-key lookups, stock-availability checks, and atomic commit — all in one function.

def place_order():
    customer_id = order_cust_id_entry.get().strip()
    phone_id    = order_phone_id_entry.get().strip()
    quantity    = order_qty_entry.get().strip()

    # ── 1. Check all fields are filled ──
    if not customer_id or not phone_id or not quantity:
        messagebox.showerror("Error", "Fill all order fields")
        return

    # ── 2. Validate quantity ──
    if not is_positive_int(quantity) or int(quantity) == 0:
        messagebox.showerror("Error", "Quantity must be a positive integer")
        return

    # ── 3. Verify customer exists ──
    cursor.execute("SELECT name FROM Customers WHERE customer_id=?", (customer_id,))
    if not cursor.fetchone():
        messagebox.showerror("Error", "Customer ID not found"); return

    # ── 4. Check phone stock ──
    cursor.execute("SELECT stock, brand, model FROM Phones WHERE phone_id=?", (phone_id,))
    current_stock, brand, model = cursor.fetchone()
    qty = int(quantity)

    if qty > current_stock:
        messagebox.showerror("Error", f"Not enough stock. Available: {current_stock}")
        return

    # ── 5. Insert order & decrement stock atomically ──
    today = date.today().isoformat()
    cursor.execute("INSERT INTO Orders(customer_id,phone_id,quantity,order_date) VALUES(?,?,?,?)",
               (customer_id, phone_id, qty, today))
    cursor.execute("UPDATE Phones SET stock = stock - ? WHERE phone_id=?", (qty, phone_id))
    conn.commit()

    messagebox.showinfo("Success", f"Order placed: {brand} {model} ×{qty}")
    refresh_dashboard()
