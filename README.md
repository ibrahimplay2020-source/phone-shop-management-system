# Phone Shop Management System

A desktop application for managing a phone retail store, including phones, customers, orders, and stock management.

## Technologies
- Python 3
- SQLite3
- CustomTkinter

## Features
- Phone management (CRUD)
- Customer management (CRUD)
- Order management
- Automatic stock updates
- Search functionality
- Dashboard statistics
- SQLite relational database

## Project Structure
- Dashboard
- Phones Module
- Customers Module
- Orders Module
